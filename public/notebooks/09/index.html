Ejercicio 9: Fundamentos de Pandas

En este ejercicio, se busca que los estudiantes se familiaricen con la biblioteca Pandas, aprendiendo a cargar, explorar y limpiar un conjunto de datos. Este ejercicio es de tipo práctico y se espera como resultado un código funcional. La dificultad es básica.

Objetivos

  • Cargar un dataset en un DataFrame utilizando Pandas.
  • Explorar el dataset para obtener información básica sobre su estructura y contenido.
  • Limpiar el dataset eliminando valores nulos y renombrando columnas para mayor claridad.

Entrada de Datos

  • Un archivo CSV que contiene información sobre árboles en parques.

Pruebas

Ejemplo de cómo debería ser el resultado esperado:

  1. ¿Cuántos árboles hay en total?

    • Respuesta esperada: Un número entero que representa el total de árboles.

  2. ¿Cuántas especies diferentes hay?

    • Respuesta esperada: Un número entero que representa el total de especies diferentes.

  3. ¿Faltan datos en algunas columnas?

    • Respuesta esperada: Un resumen de las columnas con valores nulos, si existen.

Este ejercicio está diseñado para que los estudiantes practiquen la manipulación básica de datos con Pandas, un paso esencial en el análisis de datos.
